# 시스템 정보 조회 작업지시서

## 작업 목적
- 시스템 정보를 조회하고 화면에 출력된 결과를 확인한다.

## 실행 파일과 명령
- 작업 폴더: `C:\ai-starter\system-monitor`
- 실행 파일: `system_monitor.ps1`
- 실행 명령:

```powershell
Set-Location -LiteralPath 'C:\ai-starter\system-monitor'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\system_monitor.ps1'
```

## 작업 순서
1. 파일 확인: 작업 폴더와 실행 파일의 존재 여부 및 내용을 읽기 전용으로 확인한다. 금지된 변경 작업이 포함되어 있으면 실행하지 않고 보고한다.
2. 실행: 위 명령으로 스크립트를 실행한다.
3. 결과 확인: 화면 출력, 오류 메시지, 종료 코드를 확인한다.
4. 완료 보고: 실행 여부, 주요 시스템 정보, 오류 유무를 간단히 보고한다.

## 작업 제한
- 파일 생성·수정·삭제, 프로그램 설치, 시스템 설정 변경을 금지한다.
- 조회와 화면 출력만 수행한다.
- `-ExecutionPolicy Bypass`는 해당 실행 프로세스에만 적용하며, 영구 실행 정책을 변경하지 않는다.

## 오류 처리
- 폴더·파일 누락, 실행 실패, 오류 출력 또는 비정상 종료 시 작업을 중단하고 먼저 보고한다.
- 오류 메시지와 발생 단계를 그대로 보고하며, 임의 수정·설치·설정 변경·우회 실행을 하지 않는다.
- 후속 조치는 사용자의 지시를 받은 뒤 진행한다.

## 완료 조건
- 지정된 스크립트가 오류 없이 종료되고 종료 코드가 0이다.
- 시스템 정보가 화면에 출력되었음을 확인한다.
- 주요 결과와 오류 유무를 보고한다.
- 작업 제한을 준수한다. 오류로 중단한 경우 완료로 보고하지 않는다.
