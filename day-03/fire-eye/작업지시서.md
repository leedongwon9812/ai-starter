# Codex 작업지시서: MediaPipe 눈 영역 이미지 합성

## 1. 목표

웹캠 영상에서 얼굴과 양쪽 눈을 실시간으로 추적하고, 프로젝트 폴더의 `a.png`를 각 눈의 위치·크기·기울기에 맞춰 합성한다.

## 2. 작업 범위

- Python, OpenCV, MediaPipe Face Mesh를 사용한다.
- 얼굴은 한 명만 추적한다.
- 왼쪽·오른쪽 눈의 랜드마크로 중심점, 폭, 높이, 회전각을 계산한다.
- 투명 PNG의 알파 채널을 보존한다.
- 알파 채널이 없는 이미지에는 부드러운 타원 마스크를 자동 생성한다.
- `Q` 또는 `Esc` 입력 시 카메라와 창을 정상 종료한다.
- 카메라, 이미지, 프레임 읽기 오류를 사용자에게 명확하게 출력한다.

## 3. 생성 파일

| 파일 | 역할 |
|---|---|
| `eye_overlay.py` | 웹캠 눈 추적 및 이미지 합성 프로그램 |
| `requirements.txt` | 고정된 실행 의존성 |
| `README.md` | 설치, 실행, 조정 및 문제 해결 안내 |
| `a.png` | 사용자가 제공하는 합성 이미지 |

## 4. Codex 실행 순서

1. 현재 폴더에 네 파일이 있는지 확인한다.
2. Python 버전이 3.10~3.12인지 확인한다.
3. 가상환경 `.venv`가 없으면 생성한다.
4. 가상환경을 활성화하고 `requirements.txt`를 설치한다.
5. `python -m py_compile eye_overlay.py`로 문법 오류를 검사한다.
6. `a.png`의 존재 여부와 읽기 권한을 확인한다.
7. `python eye_overlay.py`를 실행한다.
8. 카메라 화면에서 양쪽 눈 합성, 움직임 추적, `Q` 종료를 확인한다.
9. 오류가 발생하면 아래 기준에 따라 최소 범위만 수정하고 5단계부터 재검증한다.

## 5. 오류 처리 기준

| 증상 | 확인 및 조치 |
|---|---|
| `Cannot read overlay image` | `a.png`의 이름, 위치, 확장자와 파일 손상 여부 확인 |
| `cannot open camera` | 다른 화상회의 앱 종료, Windows 카메라 권한 확인, `--camera 1` 시도 |
| `No module named ...` | 가상환경 활성화 후 의존성 재설치 |
| 화면은 나오나 합성되지 않음 | 얼굴을 정면으로 두고 조명 확보, 안경 반사 감소 |
| 합성 크기가 맞지 않음 | `--scale` 값을 1.0~2.0 범위에서 조정 |
| 창이 응답하지 않음 | 터미널에서 `Ctrl+C`로 안전 종료 |

## 6. 수정 원칙

- 사용자 이미지 `a.png`는 변경하거나 덮어쓰지 않는다.
- 기존 코드 수정 전 오류 메시지와 재현 명령을 확인한다.
- 문제와 무관한 기능이나 패키지를 추가하지 않는다.
- API 키, 개인정보, 절대 경로를 코드에 넣지 않는다.
- 반복되는 코드는 함수로 유지하고 불필요한 로그는 출력하지 않는다.
- 수정 후 문법 검사와 실제 웹캠 실행을 다시 수행한다.

## 7. 완료 기준

- 프로그램이 오류 없이 시작된다.
- 얼굴이 보이면 `a.png`가 양쪽 눈을 따라 이동하고 회전한다.
- 얼굴이 사라져도 프로그램이 중단되지 않는다.
- `Q`, `Esc`, `Ctrl+C` 중 하나로 카메라 자원이 해제되며 종료된다.
