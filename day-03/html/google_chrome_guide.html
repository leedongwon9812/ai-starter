Google Chrome 사용법

인터넷 검색부터 탭, 북마크, 다운로드, 개인정보 보호까지 Chrome의 기본 기능을 단계별로 익혀보세요.

시작하기검색하기탭 관리북마크다운로드기록·보안단축키

1. Chrome 시작하기

1

Chrome 실행

바탕화면이나 작업 표시줄의 Chrome 아이콘을 두 번 클릭합니다.

2

주소 입력

상단 주소창을 클릭하고 웹사이트 주소 또는 검색어를 입력합니다.

3

페이지 열기

Enter 키를 누르면 웹사이트 또는 검색 결과가 열립니다.

🔒 https://www.google.com
⋮
주소창은 주소 입력과 검색을 모두 할 수 있습니다.

2. 인터넷 검색하기

1

주소창 클릭

현재 주소가 선택되지 않으면 Ctrl + L을 누릅니다.

2

구체적으로 입력

‘서울 날씨’처럼 원하는 내용을 명확한 단어로 입력합니다.

3

결과 선택

제목과 주소를 살펴보고 믿을 수 있는 검색 결과를 클릭합니다.

💡 이전 페이지는 왼쪽 위 ←, 다음 페이지는 →, 새로고침은 ↻ 버튼을 사용합니다.

3. 탭과 창 관리하기

새 탭

상단의 ＋를 누르면 현재 창에서 새 페이지가 열립니다.

탭 이동

상단의 탭 제목을 클릭해 여러 페이지 사이를 이동합니다.

탭 닫기

탭 오른쪽의 ×를 누릅니다. 실수했다면 Ctrl + Shift + T.

4. 자주 가는 사이트 저장하기

1

사이트 열기

저장할 웹페이지로 이동합니다.

2

별표 클릭

주소창 오른쪽의 ☆ 아이콘을 클릭합니다.

3

저장 위치 선택

이름과 폴더를 정한 뒤 완료를 누릅니다.

북마크 관리자는 오른쪽 위 ⋮ → 북마크 및 목록 → 북마크 관리자에서 열 수 있습니다.

5. 파일 다운로드하기

페이지의 다운로드 버튼을 누르면 일반적으로 PC의 다운로드 폴더에 저장됩니다. 다운로드 기록은 Ctrl + J로 확인할 수 있습니다.

⚠️ 출처를 모르는 실행 파일(.exe)이나 압축 파일은 열지 마세요. 파일 이름과 제공 사이트를 먼저 확인하세요.

6. 방문 기록과 개인정보 보호

방문 기록

Ctrl + H를 눌러 방문한 사이트를 다시 찾거나 삭제합니다.

시크릿 창

Ctrl + Shift + N. 기기에 방문 기록을 남기지 않지만 완전한 익명 기능은 아닙니다.

설정

오른쪽 위 ⋮ → 설정에서 개인정보 보호, 알림, 검색엔진 등을 관리합니다.

🔐 주소창의 사이트 주소를 확인하고, 비밀번호·카드번호를 입력하기 전 가짜 사이트가 아닌지 살펴보세요.
